DAOrganizer 0.16.0 brings reviewed bank consolidation, included routes and optional GitHub updates.

- Install **DAOrganizer-win-Setup.exe**, or extract **DAOrganizer-win-Portable.zip** and open its root `DAOrganizer.exe`. Both include .NET and 1,432 WorldLogs maps.
- Optional automatic updates live in **Settings** and are off by default. Stable releases download at startup and install after a safe exit. Current actions and open organizer-launched game clients block installation. Manual controls are also available.
- Open an item's collection details and choose **Consolidate to bank**. Review source quantities and protected items, then follow one source at a time with server-confirmed custody and banking. Coexistence and saved-login requirements apply; same-account handoff remains unsupported.
- Includes accumulated exchange, withdrawal, confirmed-delivery, recovery and route-boundary fixes. README artwork and screenshots are refreshed; user packages exclude development plans and raw evidence.

Profiles remain in `%LOCALAPPDATA%\DAOrganizer`; saved passwords stay in Windows Credential Manager. Older ZIPs require one manual upgrade to gain update support. Releases are unsigned. Included routes describe observations; access restrictions and live obstacles can still require manual handling. Synthetic checks do not prove every live-game condition.

The `.nupkg`, `releases.win.json` and `RELEASES` assets are updater files. Use the installer or portable ZIP above. `SHA256SUMS.txt` covers the published candidate assets.
